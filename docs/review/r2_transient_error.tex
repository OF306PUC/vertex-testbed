\item The phrase ``larger steady-state error, particularly during the early
stages'' seems contradictory, since early-stage errors are typically transient
rather than steady-state. Please clarify whether ``transient error'' was intended
or if the statement refers to a different metric.

\textbf{Response:} Transient error was intended. The sentence has been corrected
in the revised manuscript to read ``larger transient error during the initial
convergence phase''. The intent was to describe the effect of early-stage BLE
packet loss, which differs between purely BLE links and bridge-to-BLE links.
